Controles

Os comandos foram pensados para teclado e mouse. Use o movimento para explorar e direcione a lanterna para investigar pontos do cenário.

A Luz que Resta // Wiki

Registros reunidos para quem ainda procura respostas.

Teclado

  • W / A / S / D: movimentar o personagem.
  • Setas direcionais: alternativa para movimentação.
  • F: ligar ou desligar a lanterna.
  • Q: alternar entre os modos de luz disponíveis.

Mouse

  • Movimento do mouse: direcionar a iluminação.
  • Clique: interagir com objetos iluminados, quando houver interação disponível.
SugestãoExplore devagar. Nem todo objeto é interativo, mas detalhes do cenário podem indicar onde vale investigar.
