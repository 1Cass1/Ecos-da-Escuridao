Sobre o jogo

Ecos da Escuridão é um escape room feito para um trabalho escolar em grupo. O jogador explora uma casa, encontra objetos e resolve enigmas para tentar escapar.

Como foi feito

O jogo usa HTML para as páginas, CSS para o visual e JavaScript puro para as interações. Não usamos bibliotecas ou frameworks.

O progresso fica salvo no navegador. Há um inventário, um diário de pistas, câmeras com filtro UV, um cronômetro e finais diferentes.

O objetivo

Investigue os cômodos, combine itens e descubra a senha da porta da frente. Algumas escolhas mudam o final.
