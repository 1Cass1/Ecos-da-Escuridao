Como jogar

O jogo roda no navegador. Não precisa instalar nada.

Com mouse

  • Mova o mouse para direcionar a luz.
  • Clique nos objetos para examinar, pegar ou usar.
  • Selecione dois itens em sequência para tentar combiná-los.

Com teclado

  • Use Tab para percorrer os botões e Enter para ativá-los.
  • Na sequência dos dutos, use a barra de espaço ou o botão na tela para marcar as batidas.
  • Ative o Modo claro na tela inicial se precisar de mais luz.
